# ETSI specifications

The specifications Antares implements are ETSI's and are not redistributed
here: each PDF says no part may be reproduced without ETSI's written
permission. They are free to download. Place them in this folder under
the names below; `python3 dev/spec.py split` reads the first one.

| File | Document |
|---|---|
| `gs_cim009v010901p.pdf` | [ETSI GS CIM 009 V1.9.1](https://www.etsi.org/deliver/etsi_gs/CIM/001_099/009/01.09.01_60/gs_cim009v010901p.pdf), NGSI-LD API |
| `gs_cim013v030101p.pdf` | [ETSI GS CIM 013 V3.1.1](https://www.etsi.org/deliver/etsi_gs/CIM/001_099/013/03.01.01_60/gs_cim013v030101p.pdf), NGSI-LD test purposes descriptions |
