# ThreadSanitizer suppressions for the weekly sanitizer run.
# tokio's I/O driver hands readiness between threads through epoll; the
# sanitizer does not model that happens-before and flags the readiness
# atomics on every run. Nothing here is broker code.
race:tokio::runtime::io::scheduled_io
race:tokio::runtime::io::driver
# moka's MiniArc drops a reference with fetch_sub(Release) and pairs it with
# atomic::fence(Acquire) before freeing — the same pattern as the standard
# library's Arc. ThreadSanitizer does not model fences, so it reports the
# free as racing with the other thread's decrement. Scoped to that one
# module: a real race elsewhere in moka is still reported.
race:moka::common::concurrent::arc
# The two-broker proxy fixture (crates/antares-api/tests/common/net.rs) runs
# one thread per relayed connection and one more for that connection's return
# direction. A connection the broker is holding open is still being copied
# when the test binary exits, so the parent has not reached its join and the
# sanitizer reports the finished child as leaked. Test scaffolding, scoped to
# that module: a thread the broker leaks is still reported.
thread:common::net::
