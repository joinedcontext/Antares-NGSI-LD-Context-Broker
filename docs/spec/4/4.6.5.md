4.6.5
Supported data types for LanguageMaps
Compliant NGSI-LD implementations shall support the following data types for representing LanguageMaps:
•
A JSON object consisting of a series of key-value pairs where the keys shall be JSON strings representing
IETF RFC 5646 [28] language codes or the JSON-LD "@none" for representing default when no more
specific language is found. and the values shall be JSON strings or arrays of JSON strings. Additionally, the
languageMap encoding {"@none": "urn:ngsi-ld:null"} shall be used to represent an NGSI-LD
Null during partial update patch and merge patch (see clauses 5.5.8 and 5.5.12) and for representing deleted
Language Properties in notifications and in temporal evolutions.
