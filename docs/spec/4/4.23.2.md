4.23.2
Datatype Comparison Order
When sorting by value, and the values of Attributes are of mixed datatypes, the following comparison order (null values
last), shall be implicitly applied:
•
Numbers
•
Strings
•
Object
•
Array


•
Boolean
•
Time
•
Date
•
DateTime
•
Null
•
Attribute does not exist
Additionally, when sorting by distance, the following comparison order, shall be applied:
•
Attribute is a GeoProperty
•
Attribute is not a GeoProperty - sorted by value as shown above.
