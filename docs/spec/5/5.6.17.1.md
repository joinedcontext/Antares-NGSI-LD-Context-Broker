5.6.17.1
Description
This operation allows modification of an existing NGSI-LD Entity aligning to the JSON Merge Patch processing rules
defined in IETF RFC 7396 [16] by adding new Attributes (Properties or Relationships) or modifying or deleting
existing Attributes associated with an existing Entity.
