5.2.8
EntityInfo
This type represents what Entities, Entity Types or group of Entity IDs (as a regular expression pattern mandated by
IEEE 1003.2™ [11]) can be provided (by Context Sources).
The JSON members shall follow the indications provided in Table 5.2.8-1. id takes precedence over idPattern.
Notice that Cardinality of type being 1 implies that it is not possible to register what Entities can be provided by a
Context Source just by their id or idPattern (i.e. without specifying their type).
