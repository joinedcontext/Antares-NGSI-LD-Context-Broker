5.7.6.1
Description
This operation allows retrieving a list with a detailed representation of NGSI-LD entity types for which entity instances
exist within the NGSI-LD system. The detailed representation includes the type name (as short name if available in the
provided @context) and the attribute names that existing instances of this entity type have.
