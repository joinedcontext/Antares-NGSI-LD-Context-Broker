5.2.33
EntitySelector
This type selects which entity or group of entities are queried or subscribed to by Context Consumers. Entities can
be specified by their id, Entity Types or group of Entity IDs (as a regular expression pattern mandated by
IEEE 1003.2™ [11]).
The JSON members shall follow the indications provided in Table 5.2.33-1. id takes precedence over idPattern.
