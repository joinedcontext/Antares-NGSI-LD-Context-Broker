5.10.2.5
Output data
A JSON-LD array of matching Context Source Registrations as defined by clause 5.2.9. Instead of the
original Context Source Registration which may contain a lot of irrelevant information, implementations
should return filtered Context Source Registrations, which only contain context source registration
information relevant for the query, in particular only matching RegistrationInfo elements.
