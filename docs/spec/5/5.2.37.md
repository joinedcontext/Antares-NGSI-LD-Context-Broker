5.2.37
ListRelationship
This type represents the data needed to define a ListRelationship as mandated by clause 4.5.22. Note that in case of
concise representation, the type can be omitted (see clause 4.5.22.3) and the objectList may also be represented as an
ordered array of Strings.
The supported JSON members shall follow the requirements provided in Table 5.2.37-1.
