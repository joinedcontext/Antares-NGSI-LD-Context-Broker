5.2.38
JsonProperty
This type represents the data needed to define a JsonProperty as mandated by clause 4.5.24. In case of concise
representation, the type can be omitted (see clause 4.5.24.3).
The supported JSON members shall follow the requirements provided in Table 5.2.38-1.
