5.7.9.1
Description
This operation allows retrieving a list with a detailed representation of NGSI-LD attributes that belong to entity
instances existing within the NGSI-LD system. The detailed representation includes the attribute name (as short name if
available in the provided @context) and the type names for which entity instances exist that have the respective
attribute.
