5.6.5.3
Input data
•
Entity ID (URI) of the concerned Entity, the target Entity.
•
A selector of Entity types as specified by clause 4.17 (optional).
•
Target Attribute (Property or Relationship) to be deleted, identified by a name.
•
An optional parameter identifying the datasetId of the target Attribute instance to be deleted. Otherwise the
default Attribute instance is targeted.
•
An optional flag deleteAll indicating whether also all target Attribute instances with a datasetId are to be
deleted.
•
An optional JSON-LD @context.
