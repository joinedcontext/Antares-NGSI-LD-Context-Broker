5.2.36
ListProperty
This type represents the data needed to define a ListProperty as mandated by clause 4.5.21. Note that in case of concise
representation, the type can be omitted (see clause 4.5.21.3).
The supported JSON members shall follow the requirements provided in Table 5.2.36-1.
