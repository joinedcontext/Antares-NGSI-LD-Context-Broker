5.7.7.1
Description
This operation allows retrieving detailed entity type information about a specified NGSI-LD entity type for which entity
instances exist within the NGSI-LD system. The detailed representation includes the type name (as short name if
available in the provided @context), the count of available entity instances and details about attributes that existing
instances of this entity type have, including their name (as short name if available in the provided @context) and a list
of types the attribute can have (e.g. Property, Relationship or GeoProperty).
