5.6.3.3
Input data
•
A URI representing the id of the E to be modified (target Entity).
•
A selector of Entity types as specified by clause 4.17 (optional).
•
A JSON-LD document representing an NGSI-LD Entity Fragment.
•
An optional flag indicating whether overwriting existing Attributes within the append operation should be
permitted or denied. By default, Attribute overwrites are permitted.
