5.6.4.1
Description
This operation allows performing a partial update on an NGSI-LD Entity's Attribute (Property or Relationship). A
partial update only changes the elements provided in an Entity Fragment, leaving the rest as they are. This operation
supports the deletion of sub-Attributes but not the deletion of the whole Attribute itself.
