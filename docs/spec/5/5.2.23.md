5.2.23
Query
This datatype represents the information that is required in order to convey a query when a "Query Entities" operation
or a "Query Temporal Evolution of Entities" operation is to be performed (as per clauses 5.7.2 and 5.7.4, respectively).
The supported JSON members shall follow the requirements provided in Table 5.2.23-1.
