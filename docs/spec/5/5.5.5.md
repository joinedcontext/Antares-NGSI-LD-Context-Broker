5.5.5
Default @context assignment
If the input provided by an API client does not include any @context, then the implementation shall at minimum assign
the Core @context to such an input. In addition, the Context Broker implementation may allow configuring a
default user @context (with default terms), to be used when no user @context is provided. The Core @context shall
always take precedence.
