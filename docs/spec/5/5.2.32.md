LanguageProperty
This type represents the data needed to define a LanguageProperty as mandated by clause 4.5.18. Note that in case of
concise representation, the type can be omitted (see clause 4.5.18.3).
The supported JSON members shall follow the requirements provided in Table 5.2.32-1.
