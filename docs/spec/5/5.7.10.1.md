5.7.10.1
Description
This operation allows retrieving detailed attribute information about a specified NGSI-LD attribute that belongs to
entity instances existing within the NGSI-LD system. The detailed representation includes the attribute name (as short
name if available in the provided @context) and the type names for which entity instances exist that have the respective
attribute, a count of available attribute instances and a list of types the attribute can have (e.g. Property, Relationship or
GeoProperty).
