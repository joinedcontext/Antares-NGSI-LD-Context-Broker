5.13.3.3
Input data
•
A kind filter indicating the kind of stored @contexts that are to be included in the output list. Currently,
possible kinds are "Cached", "Hosted" and "ImplicitlyCreated" (optional).
•
A boolean details flag indicating that detailed JSON objects representing metadata about the stored @contexts
instead of simple URLs are requested (optional).
