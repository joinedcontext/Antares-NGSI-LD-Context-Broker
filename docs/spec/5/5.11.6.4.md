5.11.6.4
Behaviour
•
If the subscription Id is not present or it is not a valid URI, then an error of type BadRequestData shall be
raised.
•
If the subscription id provided does not correspond to any existing subscription in the system then an error of
type ResourceNotFound shall be raised.
•
Otherwise implementations shall delete the Context Source Registration Subscription and no
longer perform notifications concerning that Subscription.
