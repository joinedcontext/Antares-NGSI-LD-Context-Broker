5.6.8.3
Input data
•
A JSON-LD Array containing one or more JSON-LD documents each one representing an Entity as mandated
by clause 5.2.4. See clause 5.5.11.2 for information on behaviour when there is more than one instance of the
same entity in the input Array.
•
An optional flag indicating the update mode (only applies in case the Entity already exists):
-
Replace. All the existing Entity content shall be replaced (default mode).
-
Update. Existing Entity content shall be updated.
