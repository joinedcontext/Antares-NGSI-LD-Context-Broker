5.6.20.1
Description
This operation allows modification of a batch of NGSI-LD Entities according to the JSON Merge Patch processing
rules defined in IETF RFC 7396 [16] by adding new attributes (Properties or Relationships) or modifying or deleting
existing attributes associated with an existing Entity.
