5.6.9.3
Input data
•
A JSON-LD Array containing one or more JSON-LD documents each one representing an Entity as mandated
by clause 5.2.4. See clause 5.5.11.3 for information on behaviour when there is more than one instance of the
same entity in the input Array.
•
An optional flag indicating whether Attributes shall be overwritten or not. By default, Attributes will be
overwritten.
