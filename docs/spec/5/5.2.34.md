5.2.34
RegistrationManagementInfo
This type represents the data to alter the default behaviour of a Context Broker when making a distributed
operation request to a registered Context Source. The supported JSON members shall follow the indications
provided in Table 5.2.34-1. Brokers may override these recommendations.
Table 5.2.34-1: RegistrationManagementInfo data type definition
