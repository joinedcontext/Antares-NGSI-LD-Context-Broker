5.14.4.1
Description
This operation is very similar to the Query Entities operation in clause 5.7.2, except that it does not directly return
Entities, but creates and returns an Entity map including the identifiers of the Entities that are candidates to be part of
the query results. The Entity map can then be used for paginating through the included Entities.
