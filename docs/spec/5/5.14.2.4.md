5.14.2.4
Behaviour
•
If the EntityMap ID is not present or it is not a valid URI, then an error of type BadRequestData shall be
raised.
•
If the NGSI-LD endpoint does not know about a matching EntityMap for the EntityMap ID, then an error of
type ResourceNotFound shall be raised.


•
Perform an update operation on the target EntityMap using the fields specified within then JSON-LD
document. Any provided output-only fields shall be ignored.
