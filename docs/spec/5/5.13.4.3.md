5.13.4.3
Input data
•
The locally unique identifier that identifies the desired @context in the broker's internal storage. Such unique
identifiers are obtained by the client as a result of either a "Add @context" (clause 5.13.2) API operation or of
a "List @contexts" (clause 5.13.3) API operation. For @contexts of kind "Cached" this can also be the
original URL the broker downloaded the @context from.
•
A boolean details flag indicating that a JSON object representing metadata about the @context, instead of the
full content, is requested (optional).
