5.8.3.4
Behaviour
•
If the subscription Id is not present or it is not a valid URI, then an error of type BadRequestData shall be
raised.
•
If the identifier provided does not correspond to any existing subscription in the system then an error of type
ResourceNotFound shall be raised.
•
Otherwise, implementations shall query the subscriptions and obtain the subscription data to be returned to the
caller.
