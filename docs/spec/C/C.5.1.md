C.5.1
Introduction
This clause introduces some simple usage examples of the NGSI-LD API (HTTP REST binding). They are not intended
to be exhaustive but just a sample for helping readers to understand better the present document. ETSI ISG CIM
published a Developer's Primer with many more examples, see ETSI GR CIM 008 [i.21].
