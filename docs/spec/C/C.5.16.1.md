C.5.16.1 Introduction
EXAMPLE:
Give back the speed of all the Entities of type "Vehicle" that have been within the Scope
/Madrid/Centro between the 1st of August 2018 at noon and the 1st of August 2018 at 01 PM.
Note that the value of the Scope has to match for the given timeframe, which means it is possible
that it has been set before, e.g. on 1st of August 2018 at 11 AM.
