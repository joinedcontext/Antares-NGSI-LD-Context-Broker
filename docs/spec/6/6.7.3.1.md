6.7.3.1
PATCH
This method is bound to the "Partial Attribute Update" operation and shall exhibit the behaviour defined by
clause 5.6.4. The Entity identifier is the value of the resource URI variable "entityId". The attribute name is the value of
the resource URI variable "attrId". The Entity Fragment shall be contained in the HTTP request payload body.
