6.4.3.3
DELETE
This method is associated to the operation "Purge Entities" and shall exhibit the behaviour defined by clause 5.6.21,
providing entities as part of the HTTP response payload body. Figure 6.4.3.3-1 shows the query entities interaction.



Figure 6.4.3.3-1: Purge Entities interaction
The URL parameters that shall be supported by implementations are those defined in Table 6.4.3.3-1, the request
headers that shall be supported by implementations are those defined in Table 6.4.3.3-2 and Table 6.4.3.3-3 describes
the request body and possible responses.
