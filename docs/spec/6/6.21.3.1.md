6.21.3.1
DELETE
This method is associated to the operation "Delete Attribute from Temporal Evolution of an Entity" and shall exhibit the
behaviour defined by clause 5.6.13. The Entity identifier is the value of the resource URI variable entityId. The
Attribute name is the value of the resource URI variable attrId. Figure 6.21.3.1-1 shows the "Delete Attribute from
Temporal Evolution of an Entity" interaction, Table 6.21.3.1-1 shows the delete parameters to be supported and
Table 6.21.3.1-2 describes the request body and possible responses.
