6.10.3.1
POST
This method is bound to the operation "Create Subscription" and shall exhibit the behaviour defined by clause 5.8.1,
taking the subscription to be created from the HTTP request payload body. Figure 6.10.3.1-1 shows the Create
Subscription interaction and Table 6.10.3.1-1 describes the request body and possible responses.
