Resource URI:

/types/{type}
Resource URI variables for this resource are defined in Table 6.26.2-1.
Table 6.26.2-1: URI variables
Name
Definition
type
Name of the entity type for which detailed information is to be retrieved. The Fully Qualified Name (FQN) as
well as the short name can be used, given that the latter is part of the JSON-LD @context provided.
