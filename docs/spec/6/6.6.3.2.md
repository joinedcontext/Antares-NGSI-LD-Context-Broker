6.6.3.2
PATCH
This method is bound to the "Update Attributes" operation and shall exhibit the behaviour defined by clause 5.6.2. The
Entity identifier is the value of the resource URI variable "entityId". The data to be updated shall be contained in the
HTTP request payload body. Figure 6.6.3.2-1 shows the Update Attributes interaction.
