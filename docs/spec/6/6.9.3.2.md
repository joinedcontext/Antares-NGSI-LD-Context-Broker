6.9.3.2
PATCH
This method is bound to the "Update Context Source Registration" operation and shall exhibit the behaviour defined by
clause 5.9.3. The context source registration identifier is the value of the resource URI variable "registrationId". The
context source registration to be updated shall be contained in the HTTP request payload body. Figure 6.9.3.2-1 shows
the Update Context Source Registration interaction and Table 6.9.3.2-1 describes the request body and possible
responses.
