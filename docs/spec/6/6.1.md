6.1
Introduction
This clause defines the resources and operations of the NGSI-LD API. The NGSI-LD API is structured in terms of
HTTP [3], [4] verbs, request and response payload bodies.
A non-normative OAS specification [i.12] of the referred HTTP binding can be found at [i.14].
