6.5.3.4
PATCH
This method is bound to the "Merge Entity" operation and shall exhibit the behaviour defined by clause 5.6.17. The
Entity identifier is the value of the resource URI variable "entityId". The data to be updated shall be contained in the
HTTP request payload body. Figure 6.5.3.4-1 shows the Merge Entity interaction.

Figure 6.5.3.4-1: Merge Entity interaction
The URL parameters that shall be supported are those defined in Table 6.5.3.4-1 and Table 6.5.3.4-2 describes the
request body and possible responses.
