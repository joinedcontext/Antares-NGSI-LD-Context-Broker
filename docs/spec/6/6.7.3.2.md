6.7.3.2
DELETE
This method is associated to the operation "Delete Attribute" and shall exhibit the behaviour defined by clause 5.6.5.
The Entity identifier is the value of the resource URI variable "entityId". The attribute name is the value of the resource
URI variable "attrId". Figure 6.7.3.2-1 shows the Delete Attribute interaction, Table 6.7.3.2-1 shows the delete
parameters to be supported and Table 6.7.3.2-2 describes the request body and possible responses.
