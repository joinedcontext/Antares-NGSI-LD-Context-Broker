GET
This method is associated to the operation "Retrieve Subscription" and shall exhibit the behaviour defined by
clause 5.8.3. The subscription identifier is the value of the resource URI variable "subscriptionId". Figure 6.11.3.1-1
shows the Retrieve Subscription interaction and Table 6.11.3.1-1 describes the request body and possible responses.
